# Runeweaver's Chase — support and privacy

The public support and privacy page for the game, served by GitHub Pages at
<https://bazmaruta.github.io/runeweavers/>.

It is one static page, `index.html`, and it is what the App Store Connect and
Play listings point at:

- **Support URL** — App Store Connect requires one for every app.
- **Privacy Policy URL** — required by both stores. The game collects nothing,
  so the policy is short.

Edit `index.html` and push to `main`; Pages republishes within a minute or so.
